# Dispatch 22 · 客服反馈真实试跑与回放

在现有 Ops Agent 上使用配置好的模型，录制一段两轮对话。工单和商品目录均使用固定的模拟数据。

1. 「过去 30 天，哪些 SKU 的客服反馈最多？」
2. 「只看 Ridgeline 2P 呢？」

验收要求为首轮保留正确的 SKU 排名、工单件数和主要问题，追问保留 30 天范围并只显示 Ridgeline 2P，物流件数的证据链接打开后显示对应三条工单。报告区分首次通过、修正和降级，并记录模型返回的 token 用量。重复录制需要另行确认。

回放加入 `/agent/replays`，使用现有敏感内容检查和站内链接限制。浏览回放不请求模型，运行时开关维持原有设置。SKU 歧义和写请求继续由 Dispatch 21 的替身测试覆盖。部署另行确认。
